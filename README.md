# my portfolio website 
# overview of my website and project

This project is a personal portfolio website created by me to display my HTML and CSS skill developed and learned during this course. 

This project contains a home, about me, projects and contact me page with a functioning sumbit. 

This website is designed to display information, video and pictures about me and my previous projects. 

## design 
this website uses three seperate CSS files for different screens such as smartphone, table and desktop with different screen sizes. 

### full.css 
 this is the desktop stylesheet and it used when the screen width is 960px or larger.
### tablet.css
 This is used when the screen width is between 481px and 959px.
### smartphone.css
 This is used when the screen width is 480px or smaller.
## color scheme
The website uses a blue, black and white color scheme with the main colors being 
white, black, dark blue and blue 
white - is used for mainly texts.
black - is used for page background in areas needed, footer and dark areas of the website.
dark blue and blue - is used for the main page background, wrapper, headers and project section. 
## gradients
    This website uses linear gradient to improve the design of the website.

A regular linear gradient is used on the main desktop background and it changes from dark blue at the top to black at the bottom. 

An angle linear gradient is also used in the header and it uses a 45 degree angle and changes from dark blue to blue.
